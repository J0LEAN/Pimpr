# Crédits et licences des éléments tiers

Pimpr embarque quelques éléments créés par d'autres. Les fonds d'écran, les icônes
stylisées et les widgets, eux, sont dessinés par le code de l'app.

## Pictogrammes

`app/src/main/res/raw/glyphs.json` contient des tracés issus de
[Material Symbols](https://github.com/google/material-design-icons) (Google),
sous licence Apache 2.0 : <https://www.apache.org/licenses/LICENSE-2.0>.

## Polices

Toutes les polices de `app/src/main/res/font/` sont sous licence SIL Open Font 1.1.
Le texte de licence et la mention de copyright de chacune se trouvent dans
`licenses/fonts/`.

| Police | Fichiers | Licence |
| --- | --- | --- |
| Unbounded | `unbounded_medium.ttf`, `unbounded_bold.ttf` | `unbounded-OFL.txt` |
| Figtree | `figtree_*.ttf` | `figtree-OFL.txt` |
| Abril Fatface | `abril_fatface.ttf` | `abrilfatface-OFL.txt` |
| Fredoka | `fredoka_semibold.ttf` | `fredoka-OFL.txt` |
| Bebas Neue | `bebas_neue.ttf` | `bebasneue-OFL.txt` |
| Playfair Display | `playfair_italic.ttf` | `playfairdisplay-OFL.txt` |
| Comfortaa | `comfortaa_bold.ttf` | `comfortaa-OFL.txt` |
| Caveat | `caveat_bold.ttf` | `caveat-OFL.txt` |
| Monoton | `monoton.ttf` | `monoton-OFL.txt` |
| Orbitron | `orbitron_semibold.ttf` | `orbitron-OFL.txt` |
| Space Mono | `space_mono_bold.ttf` | `spacemono-OFL.txt` |
| Press Start 2P | `press_start.ttf` | `pressstart2p-OFL.txt` |

Unbounded, Figtree, Fredoka, Bebas Neue, Caveat et Space Mono ont été réduites aux
caractères latins pour alléger l'app. Les six autres, dont la licence réserve le nom,
sont les fichiers d'origine distribués par Google Fonts, non modifiés.

Les données météo et la recherche de villes viennent d'[Open-Meteo](https://open-meteo.com/),
sous licence CC BY 4.0. Le service est gratuit pour un usage non commercial.
